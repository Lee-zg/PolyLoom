## EmbedPDF 与 PDFium

`EmbedPdfVue` 使用 `@embedpdf/vue-pdf-viewer` 和 PDFium。它们不是 PolyLoom 自有代码，
保留各自版权与许可证。发布包和仓库均附
[`THIRD_PARTY_NOTICES.md`](https://github.com/Lee-zg/PolyLoom/blob/main/THIRD_PARTY_NOTICES.md)。

第三方查看器在 Web Component 内注入样式；这是运行时依赖行为，不表示这些样式改用
PolyLoom 许可证。
