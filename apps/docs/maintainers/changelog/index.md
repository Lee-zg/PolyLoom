# Changelog

## 0.1.0

首次公开版本计划包含：

- pnpm monorepo 与六个独立公开包；
- Vue/React Button；
- 类型安全 EventBus；
- SSR 安全的 EmbedPdfVue 与 iframe 回退；
- 设计令牌、CSS Layer 和单组件样式入口；
- VitePress 中文主站与英文安装入口；
- 单元、SSR、三浏览器、axe 与 tarball 消费验证；
- npm provenance、包级 Release 与统一 `v0.1.0` Release。
