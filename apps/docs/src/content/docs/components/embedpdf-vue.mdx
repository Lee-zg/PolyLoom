## 安装与按需引入

```bash
pnpm add @polyloom/vue @embedpdf/pdfium vue
```

```vue
<script setup lang="ts">
import wasmUrl from '@embedpdf/pdfium/pdfium.wasm?url';
import { EmbedPdfVue } from '@polyloom/vue/embedpdf-vue';
import '@polyloom/vue/embedpdf-vue/style.css';
</script>

<template>
  <EmbedPdfVue
    src="/documents/guide.pdf"
    :wasm-url="wasmUrl"
    title="使用指南"
    :viewer-config="{
      fonts: { ui: null, signature: null },
      stamp: { defaultLibrary: false },
    }"
  />
</template>
```

`@embedpdf/pdfium` 由 `@embedpdf/vue-pdf-viewer` 间接安装；应用若要像上例一样由打包器托管
WASM，请把它声明为直接依赖，以便包管理器和类型工具能稳定解析子路径。

## 属性

| 属性           | 类型                                        | 默认值              | 说明                                   |
| -------------- | ------------------------------------------- | ------------------- | -------------------------------------- |
| `src`          | `string`                                    | 必填                | PDF URL、相对路径或应用生成的对象 URL  |
| `title`        | `string`                                    | `'PDF 文档'`        | 外壳标题；传入空字符串时隐藏页眉       |
| `previewType`  | `'default' \| 'iframe'`                     | `'default'`         | EmbedPDF 工作台或浏览器原生回退        |
| `defaultZoom`  | `ZoomLevel`                                 | `ZoomMode.FitWidth` | 首次布局使用的缩放级别                 |
| `initialPage`  | `number`                                    | `1`                 | 首次布局后跳转的页码，并限制到有效范围 |
| `height`       | `string`                                    | `'80vh'`            | 查看区域 CSS 高度                      |
| `wasmUrl`      | `string`                                    | 官方默认值          | 自托管 PDFium WASM 的 URL              |
| `viewerConfig` | `Omit<PDFViewerConfig, 'src' \| 'wasmUrl'>` | —                   | 其余官方查看器配置                     |

`src`、`wasmUrl` 与 `defaultZoom` 等明确属性拥有最高优先级。
`defaultZoom` 会覆盖 `viewerConfig.zoom.defaultZoomLevel`，同级的 `maxZoom`、`zoomStep`
等配置会保留。`src` 或模式变化时，旧 registry 订阅会被清理并重新挂载查看器。

## 事件与模板 ref

- `init(container)`：官方 `EmbedPdfContainer` 已创建。
- `ready(registry)`：官方插件 registry 可用。
- `load({ src, documentId?, pageCount? })`：文档布局或 iframe 加载完成。
- `error({ src, phase, cause })`：动态导入、初始化、文档或 iframe 加载失败。

模板 ref 暴露 `reload()`、`container` 和 `registry`。错误界面的“重新加载”使用同一个
`reload()`，因此 `src` 不变也会创建全新实例。

## SSR、Nuxt 与异步运行时

组件模块本身不会读取 `window`、`document` 或 `localStorage`。SSR 阶段只输出带
`aria-busy` 的占位外壳，`@embedpdf/vue-pdf-viewer` 会在浏览器挂载后才异步导入。
因此 Nuxt 可直接渲染组件；如果所在页面本身只在客户端存在，也可以再包一层
`<ClientOnly>`。

## WASM、CSP 与 CORS

- 推荐使用 `@embedpdf/pdfium/pdfium.wasm?url`，让 Vite 将 WASM 作为本地构建资产发布。
- 若传入远程 `wasmUrl`，服务器必须允许跨域读取，并以 `application/wasm` 返回。
- PDF URL 同样需要允许当前站点读取；需要 Cookie 时通过官方 `viewerConfig` 配置请求。
- 严格 CSP 应允许站点自己的 worker、WASM 与 blob URL。不要把未知来源 URL 直接交给组件。
- 示例设置 `fonts: { ui: null, signature: null }`，避免查看器加载默认外部字体。
- 无需默认印章库时设置 `stamp: { defaultLibrary: false }`，避免加载官方 CDN 清单。
- 查看器默认在 Web Worker 中运行；静态托管或 CSP 环境若长期停在 0%，可设置
  `viewerConfig.worker: false` 回退到主线程，并评估大文档对交互性能的影响。

## iframe 回退

`previewType="iframe"` 使用浏览器内置 PDF 能力，适合受限设备或临时回退。浏览器对
iframe 内部 HTTP 错误的 `error` 事件支持有限，因此组件始终提供安全的“新窗口打开”
链接；需要确定状态时应由服务端先验证文档 URL。

## 主题与第三方样式

外壳样式位于 PolyLoom 的 `polyloom.components` CSS Layer，使用 `.pl-embedpdf-vue*`
命名空间和 `--pl-*` 令牌。EmbedPDF 官方查看器会在自己的 Web Component 中注入内部
样式，这是本库“JavaScript 不隐式加载 CSS”规则的第三方例外；PolyLoom 不复制或覆盖
其内部样式。
